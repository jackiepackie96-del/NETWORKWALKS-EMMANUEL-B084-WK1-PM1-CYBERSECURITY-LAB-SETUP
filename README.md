# NETWORKWALKS-EMMANUEL-B084-WK1-PM1-CYBERSECURITY-LAB-SETUP
Cybersecurity and Ethical hacking lab environment setup in oracle virtual box 
📌 Project Overview
This project is on Virtual cyber security lab and Virtual Penetration testing lab setup using VirtualBox and Kali Linux.

The role of lab is to provide a controlled environment where cybersecurity tools, network scanning, reconnaissance, vulnerability assessment and other security testing activities can be safely repeated and performed.

The lab is already set up on a private virtual network, with the ability to add more machines to the network at a later stage and target them for authorised security testing.

🎯 Objectives
The key aims of this project are to:

Install and set up VirtualBox.
Install/import Kali Linux as a virtual machine.
Make a private NAT Network for cybersecurity lab.
Set up network connections in Kali Linux.
Give the Kali VM a fixed IP address.
Test network and DNS connectivity.
Create a clean VM snapshot to recover.
Document the complete setup process.
Use a secure environment for future cybersecurity projects.
🛡️ Purpose of the Lab
The lab offers an isolated and controlled environment for cyber security learning and authorized security testing.

It can be used to do activities like:

Network reconnaissance
Port scanning
Vulnerability assessment
Packet analysis
Web security testing
Exploitation practice
Security-tool experimentation
Attention: This lab is intended for systems which are owned or explicitly permitted to be tested. Do not attempt to attack unauthorized systems, or the tools in the lab.
